aaa authentication login default group TAC-GROUP local
aaa authentication login console local
aaa authentication enable default group TAC-GROUP local
!
! EOS offers three authorization methods — group, local, none — and no
! if-authenticated. "none" is not a substitute: it means "always succeeds", in
! every state, not only during an outage. So during a TACACS+ outage an open
! session here goes inert while the Cisco boxes keep working. Documented, not
! papered over.
aaa authorization exec default group TAC-GROUP local
aaa authorization commands all default group TAC-GROUP local
!
aaa accounting exec default start-stop group TAC-GROUP
aaa accounting commands all default start-stop group TAC-GROUP
!
! Note the enable fallback differs from IOS: EOS falls back to "local" (the
! user's own password), IOS to "enable" (the device's enable secret).
